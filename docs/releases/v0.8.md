# Photo Sphere Revival v0.8

首个公开的、仅包含补丁与构建工具的版本。

## 亮点

- 显示名固定为 **Photo Sphere**，与系统相机清楚区分。
- 冷启动直接进入 Photo Sphere，隐藏不兼容模式、镜头切换和变焦入口。
- 保留五种 `Type` 选项。
- 移除全文件访问权限、推广弹层和应用内更新检查。
- 加入 2 秒旧相机信号量保护，解决 Pixel 10 Pro XL 与系统相机交替使用后的黑屏/ANR。
- 提供固定哈希的一键本地构建和每位用户独立的持久签名。

## 实机验证

Pixel 10 Pro XL (`mustang`)、Android 17 / `CP2A.260805.005`：

- 完整 360° 自然场景采集与合成：PASS
- Fish eye / Sphere 查看：PASS
- 系统相机 → Photo Sphere 热恢复：3/3 PASS
- APK v2/v3 签名与 zipalign：PASS

## Samsung

Samsung 设备尚无端到端成片证据，因此 v0.8 对 Samsung 的状态是 **UNVERIFIED**。请先阅读 `docs/compatibility.md`，提供完整型号、SoC、Android/One UI 版本，并从少量引导点的短拍开始。

## 为什么 Release 没有 APK

基础应用和原生库属于 Google/SGCam 相关权利人。本 Release 只发布补丁、脚本和验证记录。使用者必须从 Shamim 原发布页自行下载哈希匹配的标准 APK，然后在本机生成并签名成品。
