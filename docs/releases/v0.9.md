# Photo Sphere Revival v0.9

v0.9 在 v0.8 已验证的单用途 Photo Sphere 基线上加入独立启动图标，继续保持默认焦段和最小控制面。

## 亮点

- 新增钴蓝圆盘、深蓝球面环与半透明 360° 横带组成的专属图标，与 Pixel 原生相机清楚区分。
- application、启用与备用 launcher alias 均使用新图标。
- 提供 legacy PNG、adaptive icon 和 Android 13+ monochrome 主题图标资源。
- 默认构建仍隐藏不兼容的普通拍照、视频、前后镜头切换与原多镜头变焦入口。
- 不包含 v1.0/v1.0.1 主摄数码变焦实验；产品保持经实际使用验证的默认焦段。

## Samsung

Samsung 设备仍无端到端成片证据，状态为 **UNVERIFIED**。安装成功或出现取景不能证明 LightCycle 采集、拼接与图库写入可用；请先阅读 `docs/compatibility.md`。

## 为什么 Release 没有 APK

基础应用和原生库属于 Google/SGCam 相关权利人。本 Release 只发布补丁、构建脚本、图标资源与验证记录。使用者必须从 Shamim 原发布页自行下载哈希匹配的标准 APK，然后在本机生成并签名成品。
